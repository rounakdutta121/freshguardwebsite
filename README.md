# FreshGuard - HTML website demo

Static HTML version of the new FreshGuard website (English + Dutch), deployed on Vercel as a demo.

- `index.html` - homepage (EN/NL switch in place)
- English pages: services, the 4 service pages, about us, casebook, contact, privacy policy
- `nl/` - Dutch pages
- `assets/` - images and the homepage translation script

No build step: every page is a single self-contained HTML file.
